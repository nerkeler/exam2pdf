本版仅供个人学习、技术研究和功能测试，请使用自制、获授权且已去标识化的资料。

## 更新内容

- 当前学生工作区：试卷、作答、批阅、错题、统计与训练仅属于当前学生，主进程拒绝跨学生读写；切换会清理旧页面及临时上传入口，进行中的操作和未保存内容有保护。
- 学生头像与设置：侧栏底部显示头像和姓名，点击切换；可新增学生、修改姓名、选择男女中学生动漫预置头像，或选择本地 JPG / PNG / WebP 自定义头像。图片在本机裁切压缩，随学生名册备份恢复。
- 手机扫码上传：开启后显示本地生成的网址二维码，手机连接同一 Wi-Fi 扫码上传；绑定当前学生，切换后原地址失效。
- 资料与备份：统一「试卷库」，名册及当前学生随整机备份恢复；保留旧资料，恢复历史学生归属，修复维护队列和并发手机上传问题。
- 安装包瘦身：保留中英文运行资源、PDF.js 必需资产及 WOFF2 数学字体，移除冗余资源并启用最大压缩。

## 下载

- Mac M 系列：`mac-arm64.dmg` / `mac-arm64.zip`。
- Mac Intel：`mac-x64.dmg` / `mac-x64.zip`。
- Windows Intel/AMD 64 位：`win-x64.exe`。
- Linux Intel/AMD 64 位：`linux-x86_64.AppImage` / `linux-amd64.deb`。

安装包自带 Electron / Node 与 PDF 转换资源，无需另外安装 Node.js、Python 或 Poppler。`SHA256SUMS` 提供校验和，更新清单和 `.blockmap` 是辅助文件。

## 验证范围

本地 153 项自动化测试、29 项隔离 Electron 验收通过，涵盖自定义头像选图与还原、双学生隔离、二维码、备份恢复等。多平台构建工作流在各自系统执行自动化测试，并从实际应用归档验证 PDF 转图、头像和数学字体资源；构建与测试结果以对应 Actions 任务为准。

这是未签名、未经 macOS 公证的预览版本。自动化验证不等于各系统安装升级、真实小红书、AI 服务、跨设备手机上传及实体打印机均已完成人工验收。小红书登录与 AI 配置仍为本机家庭共用。

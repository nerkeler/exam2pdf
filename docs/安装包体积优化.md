# 安装包体积优化实测

日期：2026-10-28。使用本机当前 `0.1.2-preview.1` 源码，分别以原打包配置和精简配置构建 **macOS arm64**；没有用旧版本安装包代替基准。以下 MB 按 1,000,000 字节计算。

| 对比项 | 原配置 | 精简后 | 减少 |
| --- | ---: | ---: | ---: |
| DMG 下载文件 | 141.06 MB | 111.44 MB | 29.62 MB / 21.0% |
| ZIP 下载文件 | 136.46 MB | 118.02 MB | 18.44 MB / 13.5% |
| 应用文件总量（不重复计算符号链接） | 363.53 MB | 284.13 MB | 79.40 MB / 21.8% |
| app.asar | 41.66 MB | 10.29 MB | 31.37 MB / 75.3% |

## 调整内容

- 为生产依赖加入明确的排除规则。electron-builder 会自动收集生产依赖，原来的正向文件列表没有排除整包中多余的内容。
- 排除 PDF.js 的 legacy、viewer、类型定义、调试映射、重复压缩构建及未使用的 sandbox 构建。
- 保留实际使用的 PDF.js 模块和 worker、完整 CMaps、标准字体、ICC、WASM 解码资源及对应许可。
- 排除 KaTeX 源码、CLI、未使用插件及重复构建，保留浏览器使用的脚本、样式、auto-render 和完整 WOFF2 字体及许可。Electron Chromium 支持 WOFF2，不需要同时携带 TTF/WOFF 副本。
- Electron 语言资源保留英文、简体中文和繁体中文，保留默认英文回退。
- 开启 electron-builder `compression: maximum`。压缩率提高会增加构建耗时；下载文件体积与安装后文件体积是不同指标。

没有删除 Chromium、Node、ICU、视频解码器或其他核心运行库，也没有改为依赖用户安装的 Node/PDF 转换工具。

## 实际验证

- 精简后的真实应用通过启动 smoke 检查。
- 对精简前后两个 `app.asar` 分别运行 `npm run test:pdf`，每组均通过五项检查：自制两页 PDF 转 JPEG、图像尺寸与内容、损坏 PDF 拒绝、25 页上限拒绝、实际工作台及 WOFF2 数学字体加载。
- 自制 PDF 同时含中文和英文；精简前后各页 JPEG 的 SHA-256 完全一致。
- 实际 ASAR 中没有 PDF.js legacy/viewer/type 目录和 source map，auto-render 脚本仍存在。
- `hdiutil verify` 验证 DMG 校验有效，`unzip -t` 验证 ZIP 无压缩数据错误。

重现随包验证：

```sh
EXAM2PDF_TEST_ASAR="$(pwd)/release/mac-arm64/exam2pdf.app/Contents/Resources/app.asar" npm run test:pdf
```

本轮是本机未签名测试构建，没有创建或覆盖 GitHub Release。Windows 交叉构建结果见下节；Linux 和 Mac Intel 尚未在本轮重新测量。


## Windows x64 补充实测

同样使用当前 `0.1.2-preview.1` 源码，在 macOS 主机交叉生成原配置和精简配置的 NSIS 安装程序，没有关闭图标、版本信息或 ASAR 完整性资源编辑。两个构建均完成；没有配置签名证书。

| 对比项 | 原配置 | 精简后 | 减少 |
| --- | ---: | ---: | ---: |
| Windows EXE 安装包 | 128.60 MB | 114.80 MB | 13.80 MB / 10.7% |
| 解包后的应用文件 | 427.69 MB | 348.02 MB | 79.67 MB / 18.6% |
| app.asar | 41.66 MB | 10.29 MB | 31.37 MB / 75.3% |

- 实际应用为 x86-64 PE32+；NSIS 安装引导程序为 PE32，这是 NSIS 引导程序的格式，不代表应用变成 32 位。
- 仅保留 `en-GB.pak`、`en-US.pak`、`zh-CN.pak`、`zh-TW.pak` 四个语言包。
- 7-Zip 对实际 NSIS EXE 执行完整性检查，返回 `Everything is Ok`。
- 在本机 Electron 中分别加载两个 Windows 包的 ASAR，各通过五项 PDF/工作台/字体检查。含中文、英文的两页自制 PDF 精简前后 JPEG SHA-256 完全一致。

**以上是跨平台构建与资源验证，不是 Windows 原生安装或运行验收。** 尚未在 Windows 主机验证安装、卸载、系统打印和原生窗口行为。安装包位于 `release/exam2pdf-0.1.2-preview.1-win-x64.exe`，本轮未更新 GitHub Release。

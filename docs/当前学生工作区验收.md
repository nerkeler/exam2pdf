# 当前学生工作区收敛与验收

日期：2026-10-28。范围为当前开发代码；没有读取、修改或迁移日常用户资料，没有发布安装包。本轮测试使用独立临时目录和自制图片。

## 交互与范围

- 首次建立“我的学生”，支持重命名和添加；全局切换入口唯一。不再提供“未指定/全部学生”工作区、逐条改归属或手写学生姓名。
- 所有试卷、作答、错题、统计与训练均按当前学生读取，主进程同样校验 ID 归属。新记录忽略调用方伪造的 studentId。
- 同一笔记分别采集到两个学生时，各自独立保存和去重，不复用另一学生的记录。
- 正在导入、保存或请求 AI 时阻止切换。存在未保存内容时询问保留当前工作区或确认清空；取消不改变学生，确认不删除已保存资料。
- 切换后清空旧详情、图片预览、批阅内容、临时作答、勾选及分页，旧异步响应失效。搜试卷偏好按学生独立保存。侧栏显示学生头像和姓名，可从设置选择预置动漫头像或导入本地头像；自定义图片裁切压缩后保存在学生名册中，随备份恢复。
- 手机上传页面显示绑定学生，不提供修改姓名的输入框；提交伪造姓名也不能改变绑定归属。切换关闭旧地址，并处理并发开启的会话竞态。
- 只有未选中且没有记录的学生可以移除，至少保留一位；管理操作不会隐式切换当前学生。
- AI 接口和平台登录为本机共用配置，不代表独立平台账号或加密账户隔离。整机维护明确覆盖所有学生，仅在学生管理中提供。

## 数据与迁移

新增 `workspace.json` 保存当前学生，`students.json` 名册与三个记录目录共同备份/恢复。旧备份缺少名册时仍可恢复；未归属资料归入“历史资料”，缺失名册的旧 ID 各自恢复历史身份，不删除图片和批阅。历史跨学生训练关联会解除，但保留原作答和批阅。

删除学生与备份恢复均遵循维护队列，避免递归等待同一写锁；损坏名册、无效当前学生、截断归档的恢复不会替换有效资料。

## 本轮验证

- 全量自动化测试：153 项通过，无失败、无跳过。
- 真实 Electron：29 项验收通过，包含隔离目录、原有工作台/报告流程及新增双学生验收。两位测试学生各有独立记录，验证一位存在错题、另一位全对时统计不混合。
- 覆盖跨学生查看/改名/删除/图片/AI 请求拒绝；切换取消与确认；旧手机服务关闭；空学生删除无死锁；名册、当前学生及资料归属随备份恢复。
- 打包资源验证：5 项检查通过，包含新增前端上下文脚本，工作台启动、两页中英文 PDF 转图、尺寸/内容、损坏文件、页数限制与 WOFF2 数学字体加载通过。
- 桌面窄窗口与常用尺寸由原生回归和当前演示截图检查，保留原有视觉系统。辅助样式检测因本机 HTML/CSS 解析模块缺失而降级，仅能做部分规则检查；未将其描述为完整对比度或无障碍认证。

外部平台、AI 服务商、真实手机跨设备、实体打印机与各系统安装升级不在这次本地隔离回归的证明范围内。

## 更新内容

- 学生名册：支持多孩家庭。侧边栏「本机数据」卡片可切换当前学生、添加/重命名/移除学生；采集、手机上传作答、生成练习自动归属当前学生，已有试卷和作答可在详情页重新指定归属，帖子池与作答列表显示归属标签。
- AI 接口配置：切换服务商（DeepSeek / 智谱 GLM / 通义千问 / Kimi / OpenAI 兼容接口）自动带出对应的接口地址和默认模型，手动填过的自定义地址不会被覆盖。
- 外观模式：深色 / 浅色 / 跟随系统三选，跟随系统模式下实时响应系统深浅色切换；侧边栏按钮点开菜单选择。
- 采集浏览更沉浸：移除内嵌区顶部工具栏，小红书页面全出血贴边显示（触摸板双指轻扫 = 后退/前进）；弹窗打开时页面优雅让位，关闭后原样恢复。
- 深色模式修复：消除小红书页面四周的白边和弹窗让位时的白色空块，弹层期间显示品牌色柔光占位。
- 侧边栏数据总览卡片加入「学生」切换行与管理入口；使用引导重写为六步图文教程（内置示意图）。
- 许可证由 MIT 调整为 PolyForm Noncommercial 1.0.0（非商用许可）。

## 安装包

- Mac M 系列：`mac-arm64.dmg` 或 `mac-arm64.zip`。
- Mac Intel：`mac-x64.dmg` 或 `mac-x64.zip`。
- Windows Intel/AMD 64位：`win-x64.exe`。
- Linux Intel/AMD 64位：`linux-x86_64.AppImage` 或 `linux-amd64.deb`。

每个包均包含 Electron/Node 和 PDF 转换依赖，无需单独安装 Node.js、Python 或 Poppler。
`latest*.yml` / `preview*.yml` 和 `.blockmap` 为更新辅助文件；`SHA256SUMS` 覆盖安装包和更新清单。

        采集浏览说明
        
      
        Electron 应用会在独立网页视图中加载小红书，避免跨站 iframe 导致二维码空白。首次扫码登录后，登录状态会保存在应用的本机持久会话中。
        
      
        小红书页面会注入项目现有的采集脚本，在右下角提供采集按钮；普通浏览器预览不包含 Electron 网页视图。
        
      
        
    
        
          
  
    
        
      
        关于家卷 · 使用声明
        
      
        家卷（exam2pdf）面向家庭学习场景：整理打印 → 拍照批阅，全程在本机完成，学生资料不上传服务器。
        
      
        仅限非商业用途。本项目按 PolyForm Noncommercial 1.0.0 许可发布：售卖安装包、付费分发、捆绑广告或推广变现均未获授权；再分发修改版须随附许可、保留版权行并改名，不得暗示官方出品。
        
      
        资料来源请自行确认。平台公开图片不等于可任意下载传播，请使用自行制作或已获授权的试卷资料；处理真实学生信息前应取得必要授权，涉及未成年人由监护人确认处理范围。
        
      
        唯一官方渠道：github.com/nerkeler/exam2pdf，其他渠道的安装包与脚本不受官方支持。版本与运行环境可在学生管理的「整机备份与维护」中导出诊断信息。
        
      
        
    
        
          
  
    
        
      
        家卷 使用引导
        
      
        六步上手：采集 → 整理打印 → 批阅 → 复习练习 → 多学生 → 手机上传。帖子、作答与训练数据全部保存在本机；AI 批阅需要你逐次确认后才会发送作答图片。
        
      
        
        
        
          1
          
          
        
            采集试卷到试卷库
            
          
              
        • 在「采集浏览」登录小红书，登录状态保存在本机，之后无需重复扫码。
          • 
              
        • 打开一份试卷笔记的详情页，点右下角红色「采集到家卷」按钮，整套图片自动存入试卷库。
          • 
              
        • 个别图片下载失败时，刷新笔记页再采集一次即可补齐缺页（图片链接会过期）。
          • 
              
        • 顶部「搜试卷」面板可按年级 / 科目 / 教材版本 / 试卷类型组合关键词，一键跳到搜索结果。
          • 
            
        
          
        
        
        
        
        
          2
          
          
        
            整理页序，生成 PDF 或打印
            
          
              
        • 试卷库点开试卷进入详情：拖动页面卡片调整打印顺序。
          • 
              
        • 点卡片右上角 ✕ 移除封面或广告页——原文件保留，需要时可一键恢复全部页序。
          • 
              
        • 「补充图片」把本地照片并入这份试卷（比如老师另外发的补充页）。
          • 
              
        • 资料自动归属当前学生，可调整科目；「生成 PDF」存档，「直接打印」直接出卷。
          • 
            
        
          
        
        
        
        
        
          3
          
          
        
            上传作答，逐题批阅
            
          
              
        • 学生写完后在「试卷批阅」导入作答照片或 PDF（最多 24 页），核对页序后保存为本机作答记录。
          • 
              
        • 批阅方式一 · 外部 AI 网页批阅（免费）：生成作答 PDF 和固定提示词，发给豆包 / 千问 / DeepSeek 等，把返回内容粘贴回来，自动解析成逐题草稿。
          • 
              
        • 批阅方式二 · 直接 API 批阅：在「学习情况 → 应用设置」配好服务商和 Key，确认后整本发送。
          • 
              
        • 也可逐题手工批阅。所有结果都需人工核对并确认，确认后才归档错题本与学情统计。
          • 
            
        
          
        
        
        
        
        
          4
          
          
        
            错题复习与变式练习
            
          
              
        • 「错题本」按知识点、错因、时间筛选，勾选后可导出 / 打印错题集 PDF，也能标记已掌握。
          • 
              
        • 「学习情况」汇总正确率与薄弱知识点，据此生成变式练习：本地模板免费，AI 生成更贴合错题。
          • 
              
        • AI 练习只是草稿：家长检查每道题和答案、确认后才会解锁打印。
          • 
            
        
          
        
        
        
        
        
          5
          
          
        
            多孩家庭：学生名册
            
          
              
        • 点击侧边栏底部的头像和姓名切换学生；进入「学生设置」可新增学生、修改姓名和男女头像，也可移除空学生。
          • 
              
        • 新采集的试卷、手机上传的作答、生成的练习都会自动归属当前学生。
          • 
              
        • 所有页面只展示当前学生的资料；切换学生会清空未保存内容与旧页面，已保存的资料保持不变。
          • 
            
        
          
        
        
        
        
        
          6
          
          
        
            手机上传与日常维护
            
          
              
        • 「学习情况 → 应用设置」开启手机上传：手机连同一 Wi-Fi，扫描本页二维码打开上传页面（也可复制网址），直接上传作答照片，免数据线。
          • 
              
        • 同一面板里可配置 AI 接口（切换服务商自动带出接口地址和模型）、导出诊断信息、备份 / 恢复全部当前学生数据。
          • 
              
        • 深浅色外观跟随系统，也可在侧边栏手动切换；所有数据只保存在这台电脑上。

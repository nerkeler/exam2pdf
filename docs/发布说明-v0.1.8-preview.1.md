## 更新内容

- **mac 安装修复**：修复打包产物中无效的临时签名（此前 macOS 首次打开报"已损坏，无法打开"的根源）。现在为有效的 adhoc 签名，提示降级为"无法验证开发者"（系统设置可放行）。安装说明见 README 第 5 行（含下载完整性核对方法）。
- 说明：安装包仍未公证——完整的"双击即用"体验需要 Apple Developer Program（付费），当前免费路线为 xattr / 系统设置放行（见 README）。

上一版（v0.1.7）的全部改进继续有效：多语言界面、手机上传暂存持久化（收件箱重放 / 24 页上限守卫 / 跨学生归属路由）、单张容错、作答照片导出 PDF 跳过自动裁边、更新链路修复（macOS 不再每次启动静默下载约 120MB 更新包）。

## 下载

- Mac M 系列：`mac-arm64.dmg` / `mac-arm64.zip`。
- Mac Intel：`mac-x64.dmg` / `mac-x64.zip`。
- Windows Intel/AMD 64 位：`win-x64.exe`。
- Linux Intel/AMD 64 位：`linux-x86_64.AppImage` / `linux-amd64.deb`。

安装包自带 Electron / Node 与 PDF 转换资源，无需另外安装 Node.js、Python 或 Poppler。`SHA256SUMS` 提供校验和，更新清单和 `.blockmap` 是辅助文件。

## 验证范围

本地 176 项自动化测试通过；mac 包签名经 codesign --verify --deep --strict 校验通过，并对带隔离属性的副本实测可启动。多平台构建工作流在各自系统执行自动化测试，并从实际应用归档验证 PDF 转图、头像和数学字体资源；构建与测试结果以对应 Actions 任务为准。

这是未签名、未经 macOS 公证的预览版本。自动化验证不等于各系统安装升级、真实小红书、AI 服务、跨设备手机上传及实体打印机均已完成人工验收。小红书登录与 AI 配置仍为本机家庭共用。

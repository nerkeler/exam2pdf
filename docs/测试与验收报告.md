## 本轮发现并修复的问题

### 1. 搜索测量异步返回可能使用已失效的窗口/边界

原先主进程等待 `executeJavaScript` 时，用户可切离采集页、关闭窗口、调整内嵌视图宽度或导航。返回后继续读取全局边界，可能访问空值或应用旧页面坐标。

修复：测量前保存视图、边界对象和页面版本；返回后逐项核对仍属于当前上下文，失效结果直接丢弃。停止同步时同时取消待执行测量，主文档/同文档导航更新版本。5 项实际异步处理器回归覆盖 4 种失效情况和 1 种正常应用。

### 2. 备份与恢复未阻止后台入库

原先复制文件或替换库目录时，手机上传、小红书采集、训练保存仍可同时写入，可能造成不一致备份或写到正在替换的目录。

修复：备份/恢复按固定顺序持有帖子、作答、训练三个存储写队列；维护期间新工作台调用等待完成，后台写入排队后继续。回归验证维护期间两类写入均等待，维护失败也能释放队列。

### 3. 手机上传接受图片类型声明与实际字节不一致

原先只检查内容属于 JPG/PNG/WebP 中的任一种。真实 PNG 字节声明为 JPEG 时也会保存，造成 MIME、扩展名与内容不一致。

修复：按图片魔数识别实际类型，并要求与声明 MIME 一致。新增 PNG 字节伪装 JPEG 的回归，返回 400 且不入库。原本真实 HTTP 回环用例继续通过。

### 4. 移除原图后无法补充本地图片

原先补图前要求打印页序长度等于所有原图数量，错误拒绝了“移除只影响打印视图，原图保留”的合法状态。

修复：允许唯一、存在于图片清单内的打印页序子集。回归验证补图后保留被移除原文件、不自动把被移除页加回打印视图、新图排在现有页序后。

### 5. Windows 测试路径不可移植

PDF 转换路径用例将 POSIX 路径写死，Windows 上会与 `path.join` 生成结果不同。改为使用平台路径助手构造预期值；生产路径解析逻辑没有因此改变。

### 6. 打印准备早期失败遗留学生临时图片

原先清理保护从打印窗口加载阶段才开始，生成临时图片后遇到 HTML 写盘失败或原生窗口构造异常，会留下临时目录。

修复：将准备阶段完整纳入清理边界。新增实际准备处理器回归注入两类异常，验证临时图片目录删除且源图片保留；既有打印成功、取消及关闭窗口异常的清理回归继续通过（5/5）。

### 7. 空归档或截断备份可能被当成空库恢复

原先 TAR 提取在没有任何条目、只包含零块，或缺少完整结束块时仍可结束。后续验证自动创建空目录，可能把损坏文件当成合法空备份并替换当前数据。

修复：要求归档具有完整的两个零结束块，并明确包含帖子与作答类别。新增空 gzip、仅零块、无结束块和半结束块四种回归，全部拒绝恢复且当前记录保留。旧备份没有训练历史的兼容回归仍通过，备份和维护锁合计 13/13 通过。

### 8. 使用引导等界面覆盖层进入导出的报告 PDF

原生 Electron 生成 PDF 后，用 PDF 文本提取确认：首次运行保持打开的非模态使用引导会随每页报告印出。原打印样式只隐藏部分页面外壳，没有统一隐藏对话框等覆盖层。

修复：全局打印媒体样式统一排除 `dialog`、`dialog::backdrop`、`[popover]`、提示 toast 和启动错误浮层，适用于报告、错题和训练导出；报告末尾的操作工具栏与分页控件也隐藏。只改变打印媒体显示，不调用对话框关闭、不改 `open` 属性，保留导出后的交互状态。新增全打印模式 CSS 作用域检查，连同原 HTML 检查 2/2 通过；真实 PDF 内容提取和页面渲染复验已通过，证据见上文原生验收。

### 9. 深色屏幕主题污染打印纸面配色

原生 Electron 在打印媒体下切换深色主题后，报告 `.app` 和 `.surface` 计算背景仍为 `rgb(23, 29, 38)`。只设 `body` 为白色没有覆盖深色主题直接声明在 body 上的自定义变量，造成深色纸面和浅色文字。

修复：打印媒体同时覆盖 `:root`、`body` 与 `body[data-theme="dark"]` 的浅色变量，并强制 HTML、页面、应用、内容面板、错题打印区与训练结果白底深字；辅助文字、标签及重点高亮也使用纸面可读配色。规则只在打印媒体生效，不改变屏幕主题属性。源 CSS 回归明确覆盖深色 body 的特异性和全部打印内容容器，连同 HTML/覆盖层回归 3/3 通过；修复后最终全量回归 122/122 通过。原生打印媒体和浅/深色界面的真实 PDF 复验均通过，证据见上文原生验收。

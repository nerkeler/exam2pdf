# 家卷开发与验收计划

更新：2026-10-28。早期阶段记录已归档至 [历史开发记录](历史开发记录-20261019.md)，其中的 Poppler、旧版本及早期桌面阻断不再代表当前状态。

## 本轮产品边界

- 家庭单机使用，一次只工作在一位学生的上下文。学生管理用于登记姓名与维护；只有统一切换入口改变日常工作区，不提供混合全部学生的列表或统计。
- 试卷库、学生作答、错题、学情和训练均以当前学生为范围，主进程校验归属。空白试卷在试卷库打印，完成后的作答才进入批阅。
- AI 输出保持草稿，人工核对后确认；学情只统计当前学生确认的记录，不用累计数量代替学习效果。
- 小红书登录与 AI 接口为本机公共配置。搜试卷筛选条件按学生保存；手机上传会话绑定学生，切换时关闭。
- 整机备份属于学生管理中的维护操作，明确覆盖所有学生，包含名册、当前选择及学习资料；不含 API Key 与平台登录会话。

## 已完成的收敛

1. 主进程统一的学生范围存储代理，限制跨学生读写、媒体读取、AI 批阅与练习关联；采集按学生去重。
2. 当前学生持久化、旧资料归档迁移、学生删除保护；修复名册初始化错误被忽略的问题。
3. 页面切换前检查草稿与进行中操作，切换后清理详情、预览、题目、勾选、页码和筛选；迟到响应不再覆盖新学生。
4. 删除资料详情中的学生归属选择器和手写姓名入口；“帖子池”统一为“试卷库”，整机维护从学习页移入学生管理。
5. 名册和当前选择随备份事务一起恢复；兼容旧备份并保留原资料，损坏名册或无效当前选择不会替换现有资料。
6. 强制隔离测试目录，真实 Electron 双学生验收覆盖列表、统计、读写拒绝、草稿、手机上传及备份恢复。

本轮具体结果见 [当前学生工作区验收](当前学生工作区验收.md)。

## 下一阶段按顺序验收

| 顺序 | 工作 | 完成条件 |
| --- | --- | --- |
| 1 | 固定候选版本 | 源码提交、版本号、构建来源、已知限制和安装包一致；不把工作区修改当作已公开发布。 |
| 2 | 各系统安装流程 | 在干净 Mac/Windows/Linux 上安装、启动、重启、卸载，验证数据不被升级或卸载误清理。 |
| 3 | 外部集成 | 真实扫码与会话保留、单图/多图/缺页采集、手机同网段上传、AI 服务与实体打印逐项记录。 |
| 4 | 家庭小范围试用 | 观察首次建立学生、打印第一份试卷、完成第一次批阅及恢复备份的成功率、耗时与卡点。 |
| 5 | 再决定扩功能 | 依据实际使用反馈决定复习趋势、训练效果等工作；核心隔离与数据恢复未通过时不扩展新入口。 |

自动化、构建、真实外部服务和人工安装验收必须分别记录。当前本机开发修改不会自动更新已经运行的应用进程或 GitHub Release。

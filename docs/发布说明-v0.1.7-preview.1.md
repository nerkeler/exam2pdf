## 更新内容

- 多语言界面：新增 English 支持，侧边栏「切换到 English」一键切换（偏好记住，重启生效）；导航、页头、批阅导入、设置、备份等核心界面已覆盖，未覆盖的深层文案保持中文并持续补齐。
- 手机上传不再丢内容：上传的照片先落盘收件箱再交给工作台整理，整理成功才删除——整理失败或应用退出时，下次启动自动恢复；待保存页面按学生落盘，重启、语言切换、切换学生往返都不丢，切回学生会自动恢复。
- 批次容量守卫：待保存页面累计超过 24 页上限时，整批明确拒收并提示先保存或清空，不再静默截断丢失页。
- 单张容错：一张照片解析失败只跳过该张并明确计数提示，其余照常进入暂存区，不再整批丢弃。
- 跨学生归属：上传批次归属上传时的学生；切换学生后收到的批次写入对应学生的暂存文件，绝不串到当前学生名下。
- 作答照片导出 PDF 不再自动裁边：修复浅色题目/图形被当作背景裁掉丢题的问题（作答页逐像素保留；试卷库截图仍保留裁边）。此前导出的作答 PDF 如有内容缺失，用本版重新导出即可。
- 更新链路修复：移除遗留更新代码块——macOS 不再每次启动静默下载约 120MB 更新包后签名校验失败；全预发布仓库的版本查询改用 releases 列表；更新横幅出错态可见，提供「重试」与「打开下载页」。
- 数据安全：收件箱与暂存文件原子写入（防截断），损坏文件隔离为 .corrupt 留待诊断而非静默删除；删除学生时同步清理其暂存文件。

## 下载

- Mac M 系列：`mac-arm64.dmg` / `mac-arm64.zip`。
- Mac Intel：`mac-x64.dmg` / `mac-x64.zip`。
- Windows Intel/AMD 64 位：`win-x64.exe`。
- Linux Intel/AMD 64 位：`linux-x86_64.AppImage` / `linux-amd64.deb`。

安装包自带 Electron / Node 与 PDF 转换资源，无需另外安装 Node.js、Python 或 Poppler。`SHA256SUMS` 提供校验和，更新清单和 `.blockmap` 是辅助文件。

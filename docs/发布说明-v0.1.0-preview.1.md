exam2pdf 是基于 Electron 的家庭试卷工作台，可在应用内浏览小红书、手动采集获授权的试卷图片、整理页序与导出打印，并管理作答批阅、错题和学习记录。

**本预览版仅供个人学习、技术研究和功能测试。** 请使用自制、获授权且已去标识化的资料。代码开源不代表第三方试卷、平台内容或学生信息可以自由下载、传播或商用。详细数据流和使用声明见仓库 README。

### 下载选择

- **macOS Apple Silicon（M 系列）**：选择名称含 `mac-arm64` 的 `.dmg` 或 `.zip`。
- **macOS Intel**：选择名称含 `mac-x64` 的 `.dmg` 或 `.zip`。
- **Windows Intel / AMD 64 位**：选择名称含 `win-x64` 的 `.exe` 安装程序。
- **Linux Intel / AMD 64 位**：选择名称含 `linux-x86_64` 的 `.AppImage`，或 Debian / Ubuntu 系统使用名称含 `linux-amd64` 的 `.deb`。两种名称均对应 Intel / AMD 64 位 CPU。
- `.blockmap` 是构建辅助文件，不是安装程序。`SHA256SUMS` 提供下载资产的 SHA-256 校验和。

本版未提供 Windows ARM、Linux ARM 或 macOS universal 安装包。请按 CPU 架构选择文件；ZIP 是 macOS 应用压缩包，解压后使用其中的应用。

### 已包含与验证范围

- PDF 作答导入已内置 PDF.js 和 Electron 本机渲染，无需安装 Poppler，也不会为转换将 PDF 上传服务器。
- 安装包来自同一成功的多平台构建任务，Release 标签指向该任务的实际源码提交。各平台构建及随包 PDF 验证日志可在 GitHub Actions 查看。
- 本版仍是**未签名、未经 macOS 公证的测试包**，操作系统可能提示来源或签名信息；尚未配置自动升级。
- **跨平台安装、卸载、升级，以及真实小红书登录与采集、AI 服务商、实体打印机和手机跨设备上传，尚未完成逐平台人工验收。** 自动化构建与 PDF 转换通过不能替代这些验收。

AI 功能需要自行配置接口与密钥并确认发送数据。批阅和练习内容需要人工核对；不要将真实学生作答、账号会话、API Key 或个人备份上传到公开反馈。反馈请注明版本、操作系统、CPU 架构、复现步骤及去标识化日志。

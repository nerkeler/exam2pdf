## 更新内容

- 作答关联原卷：保存作答时可选关联试卷库中的原卷，之后在批阅报告、错题详情和逐题判定页都能一键查看原始题目页面；作答记录卡片和列表同步显示关联。未关联的旧记录可在报告或批阅页顶部现场补关联。
- 作答记录重命名：本地作答记录支持重命名，标题同步到批阅页、报告、错题本来源与导出文件名；重命名使用应用内对话框，帖子池重命名迁移到同一对话框。
- 批阅报告「导出 PDF」改为直接保存 PDF 文件，不再弹出系统打印面板；导出内容仅保留报告本体（自动展开全部题目、隐藏应用界面、避免单题跨页）。
- 错题本未勾选时，「生成 PDF / 直接打印」直接作用于当前筛选的全部错题，不再点了没反应。
- 错题集 PDF 格式优化：题号-来源层级更清晰、移除重复序号；自动清理 AI 公式里多余的括号（如 `(=)`、`((x,y))`、`C((3,2))`）；解题说明 ①②③④ 按步骤分行，批阅预览、错题详情与打印同步生效。
- 手机上传改为暂存核对：上传的照片进入「待保存页面」暂存区，电脑上核对页序并点「保存作答记录」后才入库；上传页提示同步更新。二维码只显示 RFC1918 局域网地址，过滤 Tailscale 等虚拟网卡。
- 批阅页导入体验：本地导入或手机上传收到照片后，编辑区整块替换导入区（拖拽框与二维码），清空或保存后自动恢复，界面聚焦当前步骤。
- 界面与体验：筛选栏与下拉框统一固定宽度对齐；侧栏折叠、页面切换与弹窗加入过渡动效并尊重系统「减少动态效果」；批阅报告页移除重复标题与状态；演示数据去掉真实校名。
- 安全与合规：新增 SECURITY.md（漏洞与滥用反馈渠道）；采集脚本加入会话采集上限与频率限制，提高被改造为批量抓取工具的门槛；采集说明补充合规提示。
- 稳定性：AI 连接测试改为探测图片输入支持；safeStorage 迁移到同步 API 并为推理模型放宽 token 余量；修复学生切换到空名册时的无限加载。

## 下载

- Mac M 系列：`mac-arm64.dmg` / `mac-arm64.zip`。
- Mac Intel：`mac-x64.dmg` / `mac-x64.zip`。
- Windows Intel/AMD 64 位：`win-x64.exe`。
- Linux Intel/AMD 64 位：`linux-x86_64.AppImage` / `linux-amd64.deb`。

安装包自带 Electron / Node 与 PDF 转换资源，无需另外安装 Node.js、Python 或 Poppler。`SHA256SUMS` 提供校验和，更新清单和 `.blockmap` 是辅助文件。

# exam2pdf 可点击原型

配套文件：[原型图.html](原型图.html)。这是用于讨论流程和页面层级的静态交互原型，笔记、批阅和数据均为示例内容。

## 页面与流程

| 页面 | 主要内容 | 可演示的交互 |
|---|---|---|
| S0 采集浏览 | Electron 内嵌的小红书网页 | Electron `WebContentsView` 作为独立顶层网页加载小红书；持久会话保留登录；采集脚本在笔记页右下角显示按钮 |
| S0b 帖子池 | 采集和导入的试卷列表 | 导入记录、重命名、删除、进入详情 |
| S0c 帖子详情 | 页面缩略图和打印操作 | 预览、拖拽排序、前后移动、移除页面、生成 PDF / 打印 |
| S1 整理打印（侧栏隐藏） | 图片页面整理 | 导入图片、排序、移除、生成 PDF / 打印反馈 |
| S1b 试卷批阅 | 作答页上传和批阅历史 | 添加页面、查看批阅草稿、展开历史记录 |
| S3 批阅确认 | AI 逐题草稿和结果选择 | 修改题目判定、确认并归档错题 |
| S4 批阅报告 | 已确认的逐题结果 | 查看统计、跳转错题本、导出反馈 |
| S5 错题本 | 错题列表、知识点和掌握状态 | 搜索、筛选、标记掌握或重新复习 |
| S6 个人学习情况 | 近期批阅、待复习错题、正确率、训练进度、薄弱知识点 | 查看对应记录、跳转错题本、生成练习；在页尾展开应用设置 |
| S7 变式练习 | 练习题和折叠答案 | 展开参考答案、打印反馈 |

## 关键交互约定

- 小红书登录页通过 Electron `WebContentsView` 加载，不使用跨站 iframe；`persist:xhs` 保存登录会话。普通浏览器只显示 Electron 运行提示。
- Electron 主进程在小红书页面注入现有采集脚本；采集浏览页不模拟小红书帖子或登录弹窗。
- 帖子详情用于整理和打印空白试卷；拖拽页面卡片可调整顺序。批阅页单独接收学生作答照片。
- 批阅结果先进入家长确认页。确认后才写入错题本，并生成批阅报告。
- AI 服务、手机上传和本地数据管理收在学习情况页底部的“应用设置”折叠区；使用按钮、状态标签、提示消息和浏览器原生确认框。
- 手机端使用固定底部标签导航，内容区预留底部空间；平板宽度下导航横向排列，页面网格随宽度调整。
- Electron 启动后自动在采集浏览页加载小红书；其他示例操作仍用于演示界面状态。

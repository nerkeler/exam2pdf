## 安装包

- Mac M 系列：`mac-arm64.dmg` 或 `mac-arm64.zip`。
- Mac Intel：`mac-x64.dmg` 或 `mac-x64.zip`。
- Windows Intel/AMD 64位：`win-x64.exe`。
- Linux Intel/AMD 64位：`linux-x86_64.AppImage` 或 `linux-amd64.deb`。

每个包均包含 Electron/Node 和 PDF 转换依赖，无需单独安装 Node.js、Python 或 Poppler。
`preview*.yml` 和 `.blockmap` 为更新辅助文件；`SHA256SUMS` 覆盖安装包和更新清单。

本版为未签名、未经 macOS 公证的预览版本。各平台通过自动化测试及随包 PDF 转换测试后发布，尚不代表安装、卸载、真实小红书、AI 服务、实体打印机及跨设备上传已全部完成逐平台人工验收。

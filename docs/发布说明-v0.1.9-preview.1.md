## 更新内容

- **全量直连**：应用不再跟随系统代理（小红书内嵌网页、更新检查均直连）。使用 Clash 等系统代理时，此前出口节点被小红书临时风控会导致内嵌网页打不开，直连后不再受代理分流影响；AI 调用本就直连，行为不变。
- **网络诊断日志**：启动时记录小红书出网方式（DIRECT/PROXY），页面加载失败的错误码、失败原因落盘诊断日志——再遇"小红书打不开"，从「设置 → 导出诊断信息」即可拿到真实错误码定位。
- **侧边栏排版优化**：底部工具区按语义分组（使用引导/关于声明 → 外观/语言 → 收起，组间细分隔线）；语言切换从整行按钮改为「中文 | English」分段控件，当前语言高亮，不再有中英混排文案。
- **启动失败提示更准确**：渲染进程被外部终止（killed，如被其他程序结束）时，提示明确为"直接重新启动即可"，不再误导去检查数据目录权限。
- 说明：安装包为有效 adhoc 签名、未公证；README 的 macOS 安装提示已按 v0.1.8 的签名修复同步更新（"无法验证开发者"可放行）。

上一版（v0.1.8）的签名修复与更早的多语言、手机上传暂存持久化、作答 PDF 跳过裁边等改进继续有效。

## 下载

- Mac M 系列：`mac-arm64.dmg` / `mac-arm64.zip`。
- Mac Intel：`mac-x64.dmg` / `mac-x64.zip`。
- Windows Intel/AMD 64 位：`win-x64.exe`。
- Linux Intel/AMD 64 位：`linux-x86_64.AppImage` / `linux-amd64.deb`。

安装包自带 Electron / Node 与 PDF 转换资源，无需另外安装 Node.js、Python 或 Poppler。`SHA256SUMS` 提供校验和，更新清单和 `.blockmap` 是辅助文件。

## 验证范围

本地 177 项自动化测试通过；mac 包经 codesign --verify --deep --strict 校验，实测系统代理开启状态下小红书以直连方式秒开、语言分段控件三态（浅色/深色/折叠）与双向切换通过端到端验证。多平台构建工作流在各自系统执行自动化测试，并从实际应用归档验证 PDF 转图、头像和数学字体资源；构建与测试结果以对应 Actions 任务为准。

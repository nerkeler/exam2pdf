# exam2pdf · 家庭试卷工作台

exam2pdf 是一个基于 Electron 的桌面学习工具，用于在同一工作台内浏览试卷资料、整理图片和打印试卷，再将学生作答转成批阅记录、错题本与学习统计。

当前项目处于开发与验证阶段，**仅供个人学习、技术研究和功能测试使用**。请优先使用自行制作、已取得授权或可合法使用的测试资料，并使用虚构或去标识化的学生信息。项目代码的开放许可不代表获得了第三方平台内容、教材、试卷或学生数据的使用授权。

## 能做什么

| 环节 | 当前功能 |
| --- | --- |
| 采集浏览 | 在 Electron 内加载小红书网页，由平台处理扫码登录；打开笔记详情后手动采集图片到本机。 |
| 搜试卷 | Electron 搜索面板按年级、学科、教材版本、试卷类型和单元组合关键词，跳转小红书站内搜索。 |
| 帖子池 | 搜索、图片与文件夹导入、重命名、预览、拖动排序、补充图片、移除页面、恢复原始页序。 |
| 整理与打印 | 生成 A4 PDF、打开系统打印窗口；在导出时处理页面方向、边缘空白、小角度倾斜和图片压缩。 |
| 试卷批阅 | 单独导入学生作答照片或 PDF，逐题人工判定、保存草稿、确认报告和分页查看结果。 |
| AI 辅助 | 使用自配 HTTPS API 生成批阅或练习草稿；也可手动将作答 PDF 和提示词交给外部 AI 网页，再粘贴结果解析。 |
| 错题与学情 | 从已确认的批阅记录归档错题，查看错因、知识点和学习统计，生成并审核针对性练习。 |
| 数据管理 | 本机保存记录和图片；导出、恢复本地备份；手动开启同一局域网内的手机作答上传。 |

AI 输出需要逐题核对。批阅草稿不会自动成为确认结果，练习题和答案需要人工审核后才能打印。学习统计来自用户确认的记录，不能替代教师评估。

## 使用流程

1. 在应用内浏览小红书，完成平台提供的登录流程，搜索并打开有权使用的试卷笔记。
2. 点击右下角“采集到 exam2pdf”，在帖子池检查采集页数，调整页序或补充本地图片。
3. 从帖子详情生成 PDF 或打印空白试卷，交给学生完成。
4. 在“试卷批阅”中导入完成后的照片或 PDF，人工批阅或请求 AI 生成草稿。
5. 核对并确认批阅，再到“错题本”和“学习情况”查看结果、准备练习。

采集工具按笔记 ID 去重，并支持缺页后重新采集。实际可采集内容、登录方式和页面结构取决于第三方平台，可能随平台调整而失效。

## 数据与使用声明

### 数据来源与内容权利

- 本项目不附带第三方试卷库、教材库或学生作答数据。采集与导入由使用者主动发起。
- 平台公开可浏览的图片不等于可以任意下载、传播或商用。请事先确认资料来源、作者授权和适用的平台规则，保留来源信息。
- 请勿使用本项目绕过登录、访问限制、付费权限或其他保护措施，勿进行批量抓取、账号共享或未经授权的传播。
- 导出的 PDF、打印件、截图和备份可能继续包含原作者内容及个人信息；分享前应重新检查。
- “仅供学习和测试”是本项目的用途说明，不会自动授予数据使用权，也不能免除使用者依法应承担的责任。

### 学生信息与第三方服务

测试时请使用虚构姓名并遮盖姓名、学号、学校、联系方式、头像、人脸、二维码等可识别信息。处理真实学生资料前，应取得所需授权；涉及未成年人时，应由监护人或有权管理资料的人确认处理与分享范围。

本项目没有提供用于接收业务数据的中心服务器，但下列操作会产生网络传输：

| 操作 | 数据去向与范围 |
| --- | --- |
| 浏览和登录小红书 | Electron 直接访问小红书及其页面资源；账号登录及平台侧的数据处理由小红书提供。 |
| 手动采集笔记 | 从当前笔记读取图片地址、标题、作者及来源链接，通过平台图片服务下载到本机。 |
| API 批阅 | 在应用确认发送后，将当前作答记录的图片、批阅提示和模型参数发送到用户配置的 AI 接口。 |
| AI 生成练习 | 将选定知识点、提示和模型参数发送到配置的 AI 接口；该请求不附带学生作答图片。 |
| AI 连接测试 | 向配置的接口发送测试文本及请求认证信息；不上传作答图片，也不能据此确认模型支持图片。 |
| 外部 AI 网页批阅 | 用户自行上传的 PDF、图片和提示词由所选外部服务处理，应用无法控制其存储、训练或保留策略。 |
| 手机上传 | 开启后通过带随机令牌的临时 HTTP 地址接收作答照片，保存在运行应用的电脑上。 |

使用 AI 功能前，请核对接口域名、服务商的数据政策与费用，并删除无关个人信息。API Key 会发送给其对应的配置接口用于认证。应用内的确认步骤不能替代对第三方服务的信任判断。

手机上传服务默认关闭，开启后监听本机网络接口；上传地址持有者可向本机提交资料。它使用 HTTP，适合受信任的局域网测试，不应通过端口转发公开到互联网。上传完成后请关闭服务；关闭服务或退出应用后临时地址失效。

### 本机存储、密钥与备份

实际数据根目录由 Electron 的 `app.getPath("userData")` 决定：

| 数据 | 保存位置或处理方式 |
| --- | --- |
| 试卷图片与帖子清单 | `userData/library/posts/` |
| 学生作答、批阅记录与图片 | `userData/library/answers/` |
| 练习及审核记录 | `userData/library/trainings/` |
| AI 服务商、模型、接口地址及加密密钥 | `userData/config/ai-settings.json` |
| 小红书登录会话 | Electron 的持久会话分区 `persist:xhs`，位于应用用户数据中。 |
| 导出备份 | 用户选择的 `.tar.gz` 文件，包含帖子、作答、训练及图片，并可包含 AI 服务商、模型和接口地址。 |

API Key 使用 Electron `safeStorage` 提供的系统安全存储能力加密；系统安全存储不可用时，应用会拒绝保存新密钥或读取密钥。此保护不等于整份学习资料已加密，也不能保护已被控制的设备或账号。

**业务图片、记录与导出的备份没有应用层加密。** 备份不包含 API Key 或小红书登录会话，但可能包含完整学生作答、姓名、来源链接，以及用户填写的接口地址等信息。请将数据目录和备份保存在受控设备上，避免上传到公开仓库、公开网盘或问题反馈附件。恢复备份会要求确认替换当前资料；恢复 AI 配置后需要重新输入密钥。

移除打印页面会保留采集原文件，可恢复原始页序；删除整份帖子或作答记录会删除对应本机文件。删除记录不会撤回已导出的 PDF、打印件、备份或已发送给第三方服务的数据。

## 开发运行

需要 Node.js 22.13.0 或更新版本、npm，以及可下载对应平台 Electron 发行版的网络。请从项目根目录运行；`npm ci` 的安装后步骤会调用官方安装器下载和校验 Electron 运行时：

```sh
npm ci
npm start
```

直接打开 Electron 自带的可执行应用会进入其默认欢迎页。请使用 `npm start` 加载项目；普通浏览器打开 `docs/原型图.html` 仅能预览部分界面，无法验证 Electron 网页视图、登录或本机功能。

核对安装的 Electron 运行时，不创建窗口：

```sh
npm start -- --check-only
```

若安装时使用了 `--ignore-scripts`，先运行 `npm run electron:install`。需要环境代理时可使用 `ELECTRON_GET_USE_PROXY=1 npm ci`，详见[打包说明](docs/打包说明.md)。若对应平台二进制下载失败，也可设置 `EXAM2PDF_ELECTRON_PATH` 指向与依赖主版本匹配的 Electron 可执行文件；启动脚本会核对版本。

学生作答 PDF 由随应用打包的 PDF.js 和 Electron 渲染引擎在本机转换，无需另行安装 Poppler，也不会为转换将 PDF 上传到服务器。

单份作答 PDF 当前限制为 50 MB、最多 24 页。AI 服务与密钥从应用设置中手动配置，不需要小红书开放平台 ID。

## 测试与验收

```sh
npm test
npm run smoke:startup
# 需要可用的图形桌面会话
npm run test:desktop
npm run test:pdf
```

`npm test` 包含本地存储、采集数据处理、批阅和学情统计、AI 响应解析、练习、备份恢复、打印布局、手机上传本机回环请求及启动脚本等测试。部分测试需要临时本机端口。

`npm run test:desktop` 使用独立临时数据目录和本地固定页面，启动真实 Electron 检查搜索覆盖视图、切页/缩放、报告分页、状态标签、公式和真实 PDF 导出。它不使用真实登录或学生数据；结果 JSON、合成报告 PDF 和画面保存在命令输出的临时目录中。真实小红书和 AI 服务验收仍需单独进行。

`npm run test:pdf` 在独立 Electron 窗口中验证离线 PDF 转图，使用自制两页 PDF 检查 JPEG 尺寸与内容、损坏文件和页数上限；可设置 `EXAM2PDF_TEST_ASAR` 指向打包后的 `app.asar` 验证随包资源。

`smoke:startup` 在桌面会话中创建临时数据目录，检查工作台脚本初始化及首帧后退出；它跳过小红书网页，不会读写日常学习资料。

自动化测试通过不等于完成真实小红书登录与采集、AI 服务商调用、打印机输出、手机跨设备上传或目标操作系统安装验收。版本发布前仍应在目标环境逐项检查，并使用测试资料复现问题。问题反馈请附操作步骤、版本、系统、已去标识化的截图或日志，不要上传作答原件、会话、密钥或备份。

本轮测试范围、逐项评分和未完成验收见 [测试与验收报告](docs/测试与验收报告.md)。

## 多平台打包

打包脚本校验 PDF.js 渲染资源与许可文件，再调用 electron-builder 生成当前目标的测试安装包。PDF 转图资源随应用分发，独立于开发机的外部工具。

```sh
npm run dist:mac
EXAM2PDF_BUILD_ARCH=x64 npm run dist:mac
npm run dist:win
npm run dist:linux

# 只检查打包前置条件
node scripts/package-app.cjs mac --check-only
node scripts/package-app.cjs win --check-only
node scripts/package-app.cjs linux --check-only
```

macOS 目标为 DMG 和 ZIP，Windows 目标为 NSIS 安装程序，Linux 目标为 AppImage 和 DEB；实际产物见[打包说明](docs/打包说明.md)。产物写入 `release/`。目标平台、架构和安装验收是不同事项；成功构建后仍需在对应系统安装、启动并验证 PDF 导入、打印和登录。

当前为未签名测试分发，macOS 公证、Windows 签名与自动升级源尚未配置。发布命令不会自动创建 GitHub Release；安装包的公开下载地址和构建结果以 [打包说明](docs/打包说明.md) 为准。

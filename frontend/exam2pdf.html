安装「小红书采集」油猴脚本（只需一次）

Safari（Mac 默认浏览器）用 App Store 的 Userscripts 扩展； Chrome / Edge 用 Tampermonkey（需在 chrome://extensions 开启「开发者模式」）

  1. Safari：App Store 装 Userscripts → Safari「设置 → 扩展」启用并允许所有网站 → 点工具栏 Userscripts 图标 → 点「+」新建脚本 → 模板全删 → 点下方「复制脚本代码」粘贴 → Cmd+S 保存
  2. Chrome / Edge：Tampermonkey 图标 → 「添加新脚本」→ 模板全删 → 粘贴脚本代码 → Ctrl+S 保存
  3. 打开小红书任意笔记页，右下角出现红色「采集到 exam2pdf」按钮
  4. 点按钮 → 按钮上显示采集进度 → PDF 自动下载，切到「② 整理打印」直接打印

风控提示：低频使用（一天几个帖子），全程手动浏览。图片链接会过期，采集前请刷新笔记页。

⚠️ 仅供个人学习与研究：采集内容版权归原作者所有，请勿分发或商用；请遵守平台条款，控制采集频率，自行承担使用风险。
